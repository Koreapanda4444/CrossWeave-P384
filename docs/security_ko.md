# 제한된 연구 결과와 남은 위험

이 후보는 외부 검토·보안 증명·상용 인증을 받은 암호가 아니다. 이번 결과는
선정한 부품 성질과 유한한 순열 표본, 규격 위반 대조군에 관한 것이다.
실제 기밀 보호 적합성, 다중 사용자/키 수명/전체 위조 한계와 프로토콜 적합성은 미확정이다.

규범 수식은 spec_ko.md, 구현 메모리/부채널 범위는 api_ko.md를 따른다.
선정한 재현 JSON은 research/results/baseline-{smoke,full}.json이다.
전체 raw 결과는 research-full 실행 시 build/research-full/에 생성한다.
JSON의 core_git_sha, core_source_sha256, runner_sha256, 생성 도메인·seed·rounds·
delta_index·dataset_index·sample_count를 함께 사용한다. 이 기록은 30번 코어에서
실행한 기준선이다. 이후 최적화도 같은 입출력 계약과 별도 회귀를 통과해야 한다.

| 분류 | 공격/관측 모델 | 실행과 영향 |
| --- | --- | --- |
| 규격 위반 대조 | 연구 전용으로 잔여 AD XOR 한 줄만 생략; key/nonce 고정·정상 암호화 질의1회 | AD00→01 치환을 결함 대조군만 수락. 정상 코어는 거부. tail1/15/17/31/33B 회귀. 실제 외부 구현의 결함 주장 아님 |

| 프레이밍 회귀 | AD/메시지 길이0..33, 각 입력3패턴의 독립 교차9조합 | 10404쌍에서 실제 순열 직전 state를 역변환으로 관측; rate XOR·domain·빈 최종 블록·oracle state·tag 일치. 9801개 서로 다른 입력쌍의 인코딩 역해독 확인 |

확인용 holdout에서 1라운드의 두 후보 및2라운드의 두 후보가 보정 유의수준
0.01을 통과했다. 4/8/12/16라운드 후보의 비유의 결과는 전체 라운드 강도의
증명이 아니다. 탐색 중 검사한 많은 출력 bit를 확인용 검정군으로 취급하지 않는다.
각 행은 key 없는 순열 관측이며 P12/P16 AEAD 위조·키 복구 공격으로 확대하지 않는다.

정확한 양측 이항검정과 pointwise99% Wilson(z=2.5758293035489004)을 사용한다.
Wilson은 동시 신뢰구간이 아니다. 고정40개와 선택 holdout12개는 별도 검정군이다.
극소 p가 float에서0으로 반올림되어도 유한한 log_p/adjusted_log_p를 보존한다.
확률1/2 또는1/4라는 국소 해석은 독립 균등 입력의 가정이며 의존하는 lane 사건의
확률을 곱해 전체 trail 확률로 선언하지 않는다.

research-smoke는 정확한 항등식·회귀가 통과 조건이고 편향은 수치만 출력한다.
research-full은 한 실행에 최대1800초이며 이번 기준선은 약13.30초에 complete였다.
시간 초과는 완료 수와 interruption을 기록한 incomplete다. 재시작은 명시된 seed로
동일 실험을 새로 실행하며 raw JSON을 기대값처럼 덮어써 회귀를 통과시키지 않는다.

# 미탐색과 후속 질문

전체 trail/hull·integral·boomerang·MITM·관련키·대규모 SAT/MILP 분석과
모드 전체의 보안 증명은 미완료다. 국소 MSB 관계가 얼마나 긴 라운드까지
이어지는지, 차분간 의존성/취소가 어떤지, keyed 초기화와 최종화가 분석 모델에
어떤 제약을 주는지 후속 연구가 필요하다. 제한된 관측을 안전 비트 수로 환산하지 않는다.
프레임 인코딩의 구분 가능성은 실제 내부 상태 충돌 부재나 인증 안전성의 증명이 아니다.
단일 fixture의 변조 거부도 모든 위조에 대한 증명이 아니다.
